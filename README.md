# Rodrigo Rocha Design — Portfólio & Landing Page Oficial

Portfólio interativo e landing page institucional de **Rodrigo Rocha Design** — Designer gráfico e de produtos brasileiro com foco no desenvolvimento conceitual e produtivo de mobiliário corporativo e residencial, além de estratégias completas de identidade visual, branding e design editorial.

---

## 🚀 Sobre o Projeto

Este projeto apresenta a trajetória criativa, manifesto, serviços especializados e portfólio de projetos autorais e corporativos desenvolvidos por Rodrigo Rocha.

- **Design Editorial & Parallax**: Camadas visuais multi-depth, tipografia editorial moderna e microinterações fluidas.
- **Galeria Interativa & Lightbox**: Modal dinâmico para visualização detalhada de catálogos, lâminas e peças de mobiliário com paginação e navegação responsiva.
- **Integração Direta**: Botões de ação direta via WhatsApp e e-mail para orçamentos e consultorias.

## 📁 Estrutura de Arquivos

```text
├── index.html          # Página principal de produção (Versão Editorial Frame Parallax)
├── index-v5.html       # Versão 5 (Editorial Split-Frame)
├── index-v6.html       # Versão 6 (Background Master Editorial)
├── index-v4.html       # Versão 4 (Parallax Multi-Depth)
├── index-v3.html       # Versão 3 (Editorial Minimalista)
├── index-v2.html       # Versão 2 (Estilo Arado)
├── index-v1.html       # Versão 1 (Layout Clássico Base)
├── css/                # Folhas de estilo modularizadas por versão (style-v5.css, style-v6.css, etc.)
├── js/                 # Scripts JavaScript de interação, modal e lightbox (main-v5.js, main-v6.js, etc.)
├── Identidade/         # Logotipos, retratos, ícones SVG e ativos da marca
├── Clientes/           # Catálogos, cases de sucesso e marcas atendidas
└── imagens/            # Fotografias de produtos, mockups e lâminas de projetos
```

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico** (SEO e Acessibilidade)
- **CSS3 Moderno** (CSS Grid, Flexbox, Custom Properties, Glassmorphism, Animações e Parallax Suave)
- **JavaScript Vanilla** (Performance máxima sem dependências externas pesadas)
- **Google Fonts** (Tipografia Outfit)

## 🌐 Publicação & GitHub Pages

Para visualizar o site publicado diretamente pelo GitHub:
1. Acesse **Settings** > **Pages** no repositório.
2. Em **Source**, selecione `Deploy from a branch`.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e acesse a URL gerada pelo GitHub Pages.
